# Harsha Engineering Works

A web application for repair request management, equipment tracking, and status monitoring.

## Tech Stack
- HTML5
- CSS3
- Modern JavaScript (ES Modules)
- [Vite](https://vite.dev/)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
